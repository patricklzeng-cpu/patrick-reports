David Ondrej 演示流程 (按时间戳)

1. MOA 概念引入 [00:00:00] – [00:03:00]

David 开场直接给 hook: "Hermes agent just released mixture of agents, this is a new feature that allows us to get frontier level results even without having access to Claude Opus 4.8 or GPT-5.6." — 强调 任何人都能跑 frontier-level, 不需要顶级订阅。

MOA 流程 (David 自己定义):

  1. 多个 agent 并行咨询: Grok / Gemini / Opus / Kimi / GLM 同步接 prompt
  2. Aggregator 综合: 通常是最强 model (default = Claude Opus 4.8 / GPT 5.5)
  3. 单答案输出: Aggregator 给出 1 个最终 answer
  4. Token 多但质量高: 比单 model 多花 tokens, 但结果逼近 frontier
"magic actually defeats models — publicly GPT 5.5 and Opus 4.8 currently are top available to us. We know better than these."

2. Hermes Agent 关键特性 [00:03:02] – [00:06:02]

David 强调 不要和 "MoE (Mixture of Experts)" 搞混:

  • MoE = 单模型内部 architecture (math/physics/coding 不同 experts, 只有部分参数激活) — 这是 inference 优化
  • MOA = 多个独立 models 协作, 各 model 独立 submit responses, 由 aggregator 综合 — 这是 orchestration 模式

两者无关。David 警告 "few of the most headlines know, influencers will skip this distinction"。

3. Hostinger VPS + cmux 终端配置 [00:06:02] – [00:09:02]

David 演示 hostinger.com landing → 选 KVM2 plan ($20/月) → 24-month discount → checkout → 拿 root SSH。Ubuntu 24 LTS + SSH key auth。

cmux 介绍 (David 的 terminal choice):

  • 免费, macOS native terminal multiplexer
  • "default multiplexor that allows you to easily create panes and launch them"
  • 比 tmux 更直观, 比 iTerm2 panes 更轻量
  • 支持 SSH + droid + PI 一键启动

SSH setup: ssh root@<VPS_IP> → 进入 Ubuntu → 默认 root home, 准备装 Hermes。

4. OpenRouter + Vercel Gateway [00:09:06] – [00:12:06]

David 强调 router 是 Hermes 真正 killer feature:

  • OpenRouter (openrouter.ai): 15-20 个 providers, "least active time" 自动路由
  • Vercel Gateway: "Versel gateway classic", 价格 couple dollars, 但功能强大 (尤其 GLM 5.2 routing 性能最佳)
  • VPS-friendly: 整个 router stack 跑在用户 VPS 里, "on VPS, act upon automations, jobs, workflows, anything autonomously turned off"

David 推荐: OpenRouter + 用户已有 ChatGPT Pro 订阅 = Hermes 自动检测你的订阅 token, 直接 route, 零额外成本。

"subscriptions, whether ChatGPT Pro, run at no cost through the Router."

5. Hermes 安装 + skills 体系 [00:12:08] – [00:18:21]

David 在 VPS 上跑 Hermes 安装 (5 分钟完成, "took minutes"):

hermes install   # 一行 install
hermes config    # 配置 router + presets + skills

Skills repo (David 的核心 deliverable):

  • 位置: davidra.com/skills (David 个人 skill repo)
  • GitHub Actions 每天自动 sync 最新 skills 到 David 的 Hermes install
  • 4 大 reference skills: GLM 5.2 / GPT 5.5 / Kimi Code / Opus 4.8 — 每个 skill 是一个 prompt template + 路由配置

David 演示如何 定义 skill (prompt + config + preset 三件套):

  • Goal-driven framing: "describe intent, what are you doing, what is your goal" — 不是 "task", 是 "broader achieve"
  • Custom CL (custom command line): 比 SL (system) 更短, 用于重复任务
  • Temperature presets: code review = 0.4 (低, predictable), brainstorm = 0.9 (高, creative)

6. MOA 实测: Hermes Router 多 model 投票 [00:18:36] – [00:27:40]

David 跑一个 204 GB dataset 的实际 MOA 测试:

  1. 第一轮: GPT 5.5 → error
  2. 第二轮: Kimi K2.7 → non-fatal warning (flag = 跳过)
  3. 第三轮: GLM 5.2 → beauty, 成功
  4. Aggregator: Opus 4.8 综合 3 轮 output, 输出最终 answer

David 强调 "universe diversity": 不同 model 对同一问题给出不同角度, aggregator 比单 model "deeper thinking case" 更 robust — "rare cases, deeper thinking, basically something practical the output end human shouldn't be able to"。

故障切换: David 演示当 Versel endpoint 慢时, 切换到 Versal cook one (Vercel 自家 endpoint), "200 tokens per second" vs "slow" — Hermes 自动 fallback。

7. Token Economics + Self-Hosting 哲学 [00:27:42] – [00:36:48]

David 把 token cost 分两类:

类型例子路由成本

Self-hosting 哲学 (David 的元论断):

  • "AI companies printing enterprise profits" — David 反对 vendor lock-in, 主张 "give data, priceless training keeping themselves, tragic"
