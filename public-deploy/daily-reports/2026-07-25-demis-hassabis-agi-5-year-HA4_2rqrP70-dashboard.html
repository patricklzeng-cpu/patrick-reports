🧩 4 大缺失能力（公认未跨越的工程鸿沟）🧩 4 missing breakthroughs (acknowledged engineering gaps)

1. Continual Learning（持续学习）1. Continual Learning

"These systems don't learn after you finish training them — after you put them out into the world. You know, they're not very good at learning further things." 当前 LLM 在训练完成后 "冻结权重"，无法像人脑那样在部署后继续学习。关键开放问题：在不破坏原有能力（避免 catastrophic forgetting）的前提下整合新信息。Brain 通过 sleep / consolidation 把短期记忆 "印" 到长期知识体系，这是 "all the leading labs are working on this" 的行业共识级开放问题。"These systems don't learn after you finish training them — after you put them out into the world." Current LLMs freeze weights after training; cannot continue learning in deployment like the brain. Key open question: integrate new info without catastrophic forgetting. Brain uses sleep/consolidation to imprint short-term into long-term memory — a leading-lab consensus problem.

2. Long-term Hierarchical Planning2. Long-term Hierarchical Planning

"These systems are not very good at planning at long time horizons, you know, many years into the future which we is... you know, with our minds we can do." 当前模型在 "几步之内" 的任务规划上已经可以（AlphaProof 走 IMO 题目链），但 "many years into the future" 级别的长链条规划仍然做不到。与 agentic AI 的核心瓶颈直接相关：AI 不能在长时域上规划 → agent 的 "长期任务分解" 持续受限于局部最优。隐含研究方向：world models / 树搜索 MCTS / planner-critic 架构。"These systems are not very good at planning at long time horizons, you know, many years into the future." Models can plan short chains (AlphaProof IMO chains) but cannot plan "many years into the future". Implied research: world models / tree search MCTS / planner-critic architectures.

3. Memory Systems（真正的记忆）3. Memory Systems (real memory)

"At the moment we have these long context windows which are kind of a bit brute force. You just put everything in them." 当前 "长上下文"（100K / 1M / 10M tokens）是 brute force — 把所有信息塞进 context window。人脑记忆是分层 + 稀疏 + 按相关性 retrieve，不是 "全量平铺"。真正的 memory system 应有 "工作记忆 / 长期记忆 / 情节记忆 / 程序记忆" 结构。与 continual learning 互补：continual learning 解决 "如何学习新信息"，memory system 解决 "如何存取已学信息"。"At the moment we have these long context windows which are kind of a bit brute force. You just put everything in them." Current long-context (100K/1M/10M) is brute force — dump everything. Human memory is layered, sparse, retrieval-based. Real memory system needs working/long-term/episodic/procedural structure. Complements continual learning: CL = how to learn new info, memory = how to store/retrieve learned info.

4. Consistency（jagged intelligence）4. Consistency (jagged intelligence)

"I sometimes call these systems 'jagged intelligences' because they're really amazing at certain things when you pose the question in a certain way. But if you pose a question in a slightly different way, they can actually still fail at quite elementary things." 他创造的 "jagged intelligence" 描述：当前模型在某些问法下表现极好（专家级），稍微改一下问法就可能在很基础的问题上失败。真正的 "通用智能" 不应有这种 jagged 分布 — 能力应该是相对平滑的。与 benchmark gaming 直接相关（特定测试集接近人类但 generalization 不行）。工程意义：评估 AGI 进展不能只看 benchmark 分数，要看 "换个问法之后还能不能稳"。"I sometimes call these systems 'jagged intelligences' because they're really amazing at certain things when you pose the question in a certain way. But if you pose a question in a slightly different way, they can actually still fail at quite elementary things." Coined "jagged intelligence" for current capability profile: expert-level on some prompts, elementary failures on slight rephrasing. General intelligence should be smooth. Directly relevant to benchmark gaming. Implication: AGI progress ≠ benchmark score; measure stability under prompt variation.
