  • [0:01:04] Alibaba OneStreamer: 实时对话 avatar (192p 当前版本, "proof-of-concept, not polished product")。关键数: 25 fps + ~200ms model-side latency, 真正的 full-duplex (边听边说边看)。
  • [0:03:31] 技术亮点: 单一 transformer 内 interleave text + audio + video; 支持 "你说我接着说" 的双工对话, 而不是轮流 turn-taking。
  • [0:03:46] 当前只发技术 paper, 没发 code (频道注: 这跟下面几个完全 open-source 的项目不一样)。

  • [0:05:46] 开源, 35GB 模型权重 (base 是 Wan 2.2), 需高端 GPU; 频道可直接下载跑。

4. 开源 Agent 编程: Ornith 1.0

  • [0:06:12] 新 MoE 模型家族: 9B / 35B / 397B (== 794GB 权重, "not too bad, 2-3 DJX Spark 拼起来")。
  • [0:06:39] 关键: 35B 版本在多个 agentic coding benchmark (Terminal Bench / SWE-Bench verified / SWE-Bench Pro) 上打平或超过 1.6T 参数的 DeepSeek V4; Medium 35B 击败 Qwen 3.5/3.6 35B + Gemma 4 (Qwen 是 "millions of downloads" 的本地最火模型)。

  • [0:08:15] (TODO: create note) Stability AI 的团队发 Arbor: 不是 "text → 3D 祈祷", 而是先给 spatial constraint (box "几何应该在这" + "这不能有" + "这几条腿必须接触地面")。
  • [0:08:55] 关键: 喂给现有 3D 生成器 (Trellis / Trellis 2) 的不是 retrain, 而是 constraint mesh — 测试中几何服从率远超前作。
  • [0:09:37] 开源 + 仅 600MB 权重 + 直接作 Blender add-on。

6. OpenAI Jalapeno chip + IBM 0.7nm 3D nano-stack

  • [0:10:00] OpenAI × Broadcom "Jalapeno": OpenAI 第一颗自家 intelligence processor, 9 个月自研, 由 OpenAI 自己模型 (GPT / Codex / internal) 加速设计 + 软件栈; gigawatt scale, multi-generation; "substantially better perf/W vs current state-of-the-art accelerators"。频道: "full stack optimization, 不只做软件了"。
  • [0:11:25] IBM 0.7nm (7 ångström) chip: "first sub-1nm chip"。关键设计: 3D nano-stack 把 transistor 垂直堆叠 + 错位, "fit nearly 100 billion transistors onto a chip the size of a fingernail" (≈ 2 倍 2nm 密度), 性能 +50% 或能效 +70%。
  • [0:12:25] 频道 framing: "Moore's law 没碰到硬上限, 还能往下走, 关键是 stacked 3D 不是 2D 缩小"。
