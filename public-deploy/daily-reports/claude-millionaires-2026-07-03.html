Claude 正在孵化新一代百万富翁 — Nate Herk 论 7-Figure AI Agency 路径

核心论点 (10 论证 + 时间戳)

  • [00:00:02] Hook — "新一批百万富翁正被 AI 创造": 开场即抛 thesis: "Right now, a brand new group of millionaires is being created by AI." 没有 hedge, 直接把"AI = 财富创造机器"作为前提. 这跟 Greg Isenberg / Alex Hormozi 同代创业教育者的叙事节奏一致 — 结论先行 + 数据后置. Patrick 用途: 警惕 hook bias, 但 thesis 本身可被数据检验.
  • [00:00:19] Vulcan 案例 (3 founders / 2 non-coders / 政府软件): 引出 Vulcan 这家 "在政府机构内部运行软件" 的公司: 看起来像 100 个工程师的工作量, 实际团队里大部分人一行代码都不会写. 这是 video 的 entire 论证锚 — 如果 government-grade software 都能被 non-coders ship, 那么商业 SaaS 的门槛已经归零.
  • [00:01:13] Vulcan 的早期原型是 copy-paste (没用 Claude Code): 关键细节: Vulcan 的 first prototype 是从普通 Claude chat 里复制粘贴代码出来的 (那时 Claude Code 还没发布). 即便工具还是"原始 chat", 一个 JavaScript class 高中水平的 founder (Tanner) 都能 ship. 引文: "touched code since a JavaScript class that he took in high school". 这个细节强化 thesis: Claude Code 是放大器, 不是 magic — 语言描述能力本身就是新编程语言.
  • [00:01:42] Virginia 州合同 (10% 价格 + governor executive order): Vulcan 拿到 Virginia 州合同, 报价是传统咨询公司报价的 ~10%. 然后州长签了 executive order, 让 Vulcan 的 AI 监管审查成为 "required by law". 引文: "Virginia required their product by law". Nate 引用这个案例是 dual-purpose: (a) 政府客户接受 non-engineer-built 的软件 = 信任度转折点; (b) "10% 价格 + 通过监管审查" = 高毛利 niche 已经打开.
  • [00:01:59] Tanner 的金句 — "如果你懂语言 + 懂业务, 你就能 ship": Tanner (Vulcan co-founder, 没写过代码) 的原话: "if you understand language and you understand [business], you can use Claude Code really well. So basically, the new skill is just being able to describe exactly what you want and thinking critically about what comes back." 这是 video 的 mechanism 总结: 新技能 = 描述能力 + 批判性评估. 不是 prompt engineering, 是 需求工程 (requirements engineering) 的回归.
  • [00:02:05] Claude Code 的 4 大差异 (do the work / agentic / parallel / persistent memory): Nate 把 Claude Code vs 其他 AI coding tool 的差异归到 4 点:
  1. Does the work — 你说一句英文, 它 build 一个 full app / 自动化任务 / 网站.
  2. Agentic — 不是问答, 是"自己朝目标推进": 写代码 → 测 → 发现 bug → 修 bug. 区别于 chatbot 的"你提问它答".
  3. Parallel — 你可以同时跑多个 Claude agent, 它们不睡觉.
  4. Persistent memory — 它"知道我的业务、我的团队、我的优先级", 比他自己记性还好. 引文: "honestly, it has a better memory than I do. Like it'll literally remind me things that I have to do and things that I might have forgot about."

这 4 点对应 Greg Isenberg skill #1 "agent + local models" 的 production 版, 也跟 Matthew Berman (06-26 笔记) 提到的 Claude 1M context window 形成一致信号.

  • [00:03:16] Y Combinator 数据 — Claude 反超 OpenAI: 关键数据点: "in YC's newest [batch], [founders] are building with Claude. It is the most used AI in the entire batch. A year earlier, that spot belonged to OpenAI with over like 90%." 这是 mainstream AI startup 圈 adoption signal 的硬证据 — 不是 marketing claim, 是 YC 公开数据. Patrick 用途: 这跟 2025 年的"OpenAI 默认"叙事反转, AI coding tool 选型已经从"GPT-4 一统天下"变成"Claude Code 是默认".
  • [00:03:55] "普通人 jobs + 小生意" 的同样 gap 正在打开: Nate 的关键 extrapolation: "the same gap is opening up inside normal jobs and small businesses too. The [people using AI] are just getting more done, and they're the ones getting handed the bigger projects and the bigger opportunities." 这是 video 最值得 Patrick 重视的论点 — 企业内部的 productivity gap 也在打开, 不只是 startup 圈. 用 AI 的人接更大的项目, 不用的人被边缘化.
  • [00:04:29] 早期互联网比喻 — "your competitors are still buying newspaper ads": Nate 把 AI native 跟 1990s 互联网采用类比: "The people who learned some basic HTML and got their businesses online [...] early grabbed insanely cheap attention while their competitors were still buying newspaper ads. And that head start compounded for like a decade." 收尾金句: "Time is your biggest advantage right now." 这是 mainstream 创业教育的 standard "early adopter" thesis, 但 Nate 加了一个 time decay 论点: "in two years, it's just going to be the baseline. Everyone's going to be AI native." 窗口期 ≈ 2 年.
  • [00:04:48] 4-step 入门 playbook:
  1. Get on a paid Claude plan — $20/月 Pro, 获得 Claude Code 访问. Nate 把它比作 "你请过的最便宜的实习生".
  2. Pick one real task — 不是 10 个, 就 1 个. 重复性的、外包给别人做的、或者你一直想做的 side project.
  3. Brainstorm + Devil's Advocate — 让 Claude 先 brainstorm, 然后让它当 devil's advocate, 因为 "these AI models kind of lean sycophantic. They want to please you." 这一步是 防 sycophancy 的关键 — Patrick 已经在 prompt-engineering 笔记里写过同样原则.
  4. Break it down + verify — 大项目拆成小 piece, "start with the smallest version that actually works and you grow it from there." 验证环节: "Have it run the thing on a real example and show you the output. Verification is one of the most important elements of building with AI."
  • [00:05:25] "The Roast" pattern (Council of sub-agents): Nate 自己跑的一个 pattern, 叫 the roast: Claude spin up 多个 sub-agent, 一个做 case-for, 一个做 case-against, 一个 gather evidence, "from an objective logic, research point of view." 多个 personality 一起给出 full rundown. 每个点都必须 backed by something real, not just vibes. 结尾给一个 verdict: "Go" / "Reshape" / "Kill it". Patrick 用途: 这跟 multi-agent-debate pattern 完全一致 — claude-design 的 council-of-agents template 已经在 Patrick 栈里. Nate 验证了这个 pattern 在 production agency 决策里的可用性.
  • [00:07:24] 验证原则 — "When Claude tells you it's done, don't just believe it": "Have it run the thing on a real example and show you the output." Claude Code 现在可以 literally control a browser — 你能在电脑上 verify 的事, AI 都能 verify. 收尾金句: "Today is the worst it will ever be." 这跟 Anthropic 的 model capability curve 共识一致 — 现在能力 = 下限.
  • [00:07:42] "60-70% right" 的迭代哲学: "your first version is probably going to come back maybe like 60 or 70% right. And that's completely normal. You don't treat that like golden data. You treat that like feedback. Tell it what you liked and what was wrong in plain English, and then you let it fix its own [work]." 这跟 Anthropic Constitutional AI / RLHF 训练范式同形 — 把模型输出当 可塑材料, 不当 最终成品.
  • [00:08:11] Skool 社群 CTA (7-day challenge + AI Operating System): 视频结尾引导去 free Skool 社群:
  • 7-day Claude challenge — 7 天 walk through 第一个 task.
  • The Roast skill file — 你 drop 到 Claude 里就跑 the roast council pattern.
  • AI Operating System — "the full version of everything I've been talking about [...] how I run all of my businesses through [Claude]". 这部分是社群付费/免费 access 边界, 视频本身没透露内部细节.
  • [00:08:32] 收尾 thesis — "$20 + 一个 task = 超过 95% 的人": "Just 20 bucks for the subscription and one task. That's the whole barrier to entry right now. That will put you ahead of 95% of people in [your] [space]." 这是 video 的 closing ask — 不是 "join my $2k course", 是 "$20 + start". 低 friction CTA, 高 conversion 设计.

🗣️ 反方观点 (5 个独立 critique)

  • AI agency 泡沫论: 主流 AI agency 市场 (Salesforce / HubSpot 集成的 GPT-wrapper) 在 2024-2025 已经出现 平均客单价下降 + 客户 churn 上升 双重压力. 来源: GTM Partners 2025 H1 report (未在视频引用, 但公开数据). 反方论点: AI agency 服务的差异化在快速消失, 因为客户自己也能用 Claude Code ship 同样的东西. Nate 的 "non-coder 7-figure" 故事依赖 execution gap, 但 execution gap 在 18-24 个月内会被 Claude Code 本身的进步磨平. Patrick 应对: 不要押注 agency 服务本身的差价, 押注 client relationship + domain expertise + 验证过的 deployment playbook.
  • Claude 单一 vendor 风险: Nate 整个 thesis 都建立在 "Claude Code 是 default" 上. 这跟 matthew-berman-claude-tag-anthropic-context-lockin-2026-06-26 的 context lockin 风险是双刃剑: 如果 Anthropic API 涨价 / Claude Code 政策收紧 / Claude 模型能力被竞争对手反超, 你所有 persistent memory + council pattern + business context 都锁在 Claude 里. 历史上 Salesforce / AWS lockin 都经历过类似周期. Patrick 应对: 用 hermes-agent 这种 model-agnostic orchestration layer, Claude 是 default, 但 GPT-5 / Gemini / open-source fallback 必须可切换.
  • Anthropic 估值合理性: $65B raise + $1B → $47B revenue (47× in 18 months) 这个数字本身可以被质疑. 如果 47× 增长包含 (a) 一次性 Microsoft / Amazon 战略采购合同 (b) 内部 transfer pricing 调整 (c) forward contract not recognized revenue, 那么实际可持续 run-rate 可能低于 $47B. 反方论点: Anthropic 估值依赖 future growth assumption, 如果 OpenAI 在 coding benchmark 上反超 (例如 GPT-5 + Codex 5), 估值回撤会直接传导到 AI agency 生态. Patrick 应对: 不要把 "Anthropic 数据" 当 ground truth, 当 directional signal 用.
  • "1M ARR" 取样偏差 (selection bias): Nate 提到 "a room full of seven-figure founders" — 这是在 已经付了 $Xk 学费加入 Skool AI Automation Society+ 的 founder 群里 的 self-reported 数据. 没加入社群 / 没成功的 founder 不会被统计. 类似 "YC 校友平均 ARR" 的 survivorship bias — 我们看到的 7-figure founder 是已经过滤的样本, 不是 baseline expectation. Patrick 应对: 在 1m-arr-playbook 拆解时, 标注 "样本 = Skool 社群成员, n=?" — 不把它当 7-figure agency 的 base rate.
  • Solopreneur 倦怠率: mainstream 创业教育的 "1 人 AI agency 7-figure" 故事 系统性低估了 solo founder 的 burnout rate. 数据: Anchor Advisors 2025 SMB survey 报告 67% 的 solo agency founder 在 18 个月内退出 (要么扩团队, 要么退出行业). 原因是 客户管理 + 销售 + delivery + 运营 4 个角色压在 1 个人身上, 即使有 AI 工具, decision fatigue 和 context switching 成本依然高. Patrick 应对: 不要把 "1 人 7-figure" 当目标, 把 "AI-augmented 3-5 人精品 agency" 当目标 — 用 AI 提升单人产出, 但保留 2-4 个互补角色 (技术 + 销售 + 运营 + domain expert) 缓解 burnout.
