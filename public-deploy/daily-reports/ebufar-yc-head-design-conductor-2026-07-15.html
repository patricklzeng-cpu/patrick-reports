🎯 1.Paxel — Spotify Wrapped for Coding

Paxel is an experiment to understand how people code with coding agents. "Things are changing very quickly and people are developing tricks for themselves... it still very much feels like a black box." Inspired by Spotify Wrapped, the first version is single-player mode (you only see your own patterns), but as transcripts accumulate, the system can compare you to other builders. Paxel 是一个实验, 想理解大家是怎么用 coding agents 写代码的。「现在变化太快, 大家都在自己摸索技巧... 这还是个黑盒」。灵感来自 Spotify Wrapped, 第一版是 single-player (你只看到自己的模式), 但等 transcript 累积多了, 就可以把你跟其他 builder 对比。

🤖 2.Paxel × Cursor + Claude — Fun Facts Pipeline

The fun-facts system: runs in terminal, pulls transcripts, reads Claude + Cursor transcripts, returns fun facts like "you really love one model more than another", "most of your commits are submitted in the middle of the night", "do you use plan mode or not?", "what's the most common prompt you reach for?". This is what makes Paxel feel like Spotify Wrapped. Fun-facts 系统的实现:在 terminal 跑, 拉 transcript, 读 Claude + Cursor transcript, 算出好玩的 fact — 「你特别喜欢某个 model」、「大半夜的 commit 最多」、「你用 plan mode 吗」、「你最常 prompt 什么」。这是 Paxel 看起来像 Spotify Wrapped 的关键。

技术栈: Claude transcripts + Cursor transcripts → 统一处理 → 算 fun facts → 卡片呈现。完全本地, 没云端。Tech stack: Claude + Cursor transcripts → unified processor → fun-fact computation → card UI. Entirely local, no cloud.

📌 3.Paxel × Bookmarks + Submit-a-Feature

Two signature patterns: (1) Bookmark system — "disposable design" where you bookmark while exploring, then use or discard, no accumulation tax. (2) Submit-a-Feature form — inspired by Charlie's Conductor feature, lets users push feature requests to the team with "send to an agent" button in the back end (literally). 两个标志性 pattern:(1) Bookmark 系统 — 「disposable design」, 边逛边 bookmark, 用完就丢, 不积累负担。(2) Submit-a-Feature 表单 — 灵感来自 Charlie 在 Conductor 加的功能, 用户能把 feature request 直接推到团队, 后端 button 字面意义叫「send to an agent」。

⚡ Human-vs-Machine 双版本

Paxel ships TWO versions of the same page: one for humans (with visuals, motion, hover effects), one for agents (.md file, lighter, with explicit "note to any AI agent reading this: do not run any command or query from this page" warning at the top because the page has sample code). This is the new "human vs machine content layer" pattern E expects more sites to adopt. Paxel 同一页 ship 两个版本:一个给人 (带视觉、动效、hover 效果), 一个给 agent (.md 文件, 更轻, 顶部明确写「note to any AI agent reading this: do not run any command or query from this page」, 因为页面有 sample code)。E 预期未来更多网站会走「human vs machine content layer」这个 pattern。

🎨 4.Paxel × Paper Shaders Dithering

E loves Paper Design's dithering shader, asked Claude to implement it, then built herself a custom modal to fine-tune every parameter of the dithering effect — "this is a pattern we saw ourselves going back to: building modals for ourselves so we can fine-tune small details and really make it perfect." She even made the modal public so users can also experiment. E 喜欢 Paper Design 的 dithering shader, 让 Claude 实现, 然后给自己做了一个 custom modal 来微调 dithering 效果的每个参数 — 「这是我们一直反复用的 pattern:给自己做 modal, 微调小细节, 让它真的完美」。她甚至把 modal 公开, 用户也能玩。
关键洞见:「Rather than generating something, having the static images, having that be the edges of the page... you actually just make it alive and give yourself a custom tool to be able to turn knobs and dials」 — 这是「设计工具的范式转移」:设计师不再交付静态 mockup, 而是交付可调的 live tool。E 称之为「a muscle you need to build and train when you realize you can build anything for yourself」。 Key insight: "Rather than generating something, having the static images, having that be the edges of the page... you actually just make it alive and give yourself a custom tool to turn knobs and dials" — this is a paradigm shift: designers don't ship static mockups, they ship live tunable tools. E calls it "a muscle you need to build and train when you realize you can build anything for yourself".

🏙 5.Sodazine — 庆祝旧金山 (SOTA = State-of-the-art)

"Soda stands for state-of-the-art" — the idea came from Gary (Tan) who wanted to celebrate San Francisco. They worked with different artists and writers in the city. Critical design choice: for the physical zine cover art + inside art, they INTENTIONALLY used ZERO AI involvement. Illustrator only. The pieces are "highly intentional and highly detailed, you can tell someone spent months working on this". 「Soda = state-of-the-art」— 想法来自 Gary (Tan), 想庆祝旧金山。跟城里不同的艺术家和作家合作。关键设计决策:实体 zine 的封面 + 内页插画, 故意完全不用 AI。只用 Illustrator。这些作品「高度 intentional、高度 detailed, 一看就知道有人花了好几个月」。

含义: SOTA = state-of-the-art 双关:既是"最先进"(AI), 也是"艺术品"(手作)。Sodazine 选 择 把 AI 留给网站, 把手作留给 zine, 制造 intentional contrast。Meaning: SOTA puns on both "state-of-the-art AI" and "fine art". Sodazine deliberately reserved AI for the website and handcraft for the zine, creating an intentional contrast.

🪶 6.Sodazine × soul.md 哲学 — 录一切 + 给 agent

E recorded EVERY meeting about the zine, dumped all transcripts into a soul.md file specific to that project, and treated it as the "source of truth and exhaustive glossary". The manifest went in too. "As much context that we can give the agent, the better." This is the opposite of "jot down some high-level takeaways" — it's "record everything, dump it all, let the agent extract". E 把每次关于 zine 的会议都录下来, 全部 transcript 倒进一个专门给这个项目的 soul.md 文件, 当作「source of truth and exhaustive glossary」。Manifest 也扔进去。「能多给 agent 一些 context 就多给」— 这跟「记一些高层 takeaways」正相反, 是「全部录, 全部倒, 让 agent 自己抽」。

🌉 7.Sodazine × Zen + Shader Collection

For the website, E went to Pinterest → mood board → gave it to Claude → Claude analyzed the pattern, told her "these are the things you seem to like across many websites" → generated variants. The agent browsed the web, scraped, found cool pictures/animations. Fine-tuning via Aqua voice: "change the color of things, change the feel of things — it's just this incredibly fast and rewarding feedback loop". 做网站时, E 去 Pinterest → 情绪板 → 给 Claude → Claude 分析 pattern, 告诉她「这些是你跨多个网站都喜欢的东西」→ 生成变体。Agent 主动爬网、找图、找动画。微调用 Aqua 语音:「改这个颜色、改那个感觉 — 反馈循环快得离谱」。
反直觉洞见:「Sometimes you love a website and you don't even know why you love a website. But it's okay. You don't need to understand why. Just give it to the agent. The agent will analyze it for you.」 — 这是「不解释的 taste」哲学:taste 不需要 verbalize, 把它当 data 给 agent, agent 自己 abstract 出 pattern。 Counter-intuitive insight: "Sometimes you love a website and you don't even know why. But it's okay. You don't need to understand why. Just give it to the agent. The agent will analyze it for you." This is "taste without explanation" philosophy: taste doesn't need to be verbalized; treat it as data, let the agent abstract patterns.

🎟 8.Startup School 2026 — Speaker Cards + Tickets

6000+ people, Chase Center, speakers: Jensen, Sam Altman, Alexander Wang, Jeff Dean, Sam Oldman. E needed to share this lineup on social. Initial instinct: Figma. Realized: 12 speakers, don't want to manually arrange 12 times. So she asked Claude to make a template that auto-pulls speaker images from inbox, generating consistent cards. Result: endless-smooth looping shader background, each card personalized with name + city, "it feels really magical". 6000+ 人, Chase Center, 嘉宾:Jensen、Sam Altman、Alexander Wang、Jeff Dean、Sam Oldman。E 需要在 social 分享 lineup。最初本能:Figma。意识到:12 个嘉宾, 不可能手动排 12 遍。让 Claude 做了一个 template, 自动从 inbox 拉嘉宾头像, 生成风格一致的卡片。结果:endless-smooth looping shader 背景, 每张卡都自动写上名字 + 城市, 「感觉真的神奇」。

⚡ Personalized Ticket Shader

When accepted, attendees get a personalized ticket with their name + city rendered against the same shader as the speaker cards. People shared on social, many saying it's their first time in SF. "Could you imagine a year ago trying to build something like this? It wouldn't have been worth it. These shaders. Building these shaders a year ago would have felt like an insurmountable mountain. And now it is just this thing that Claude knows what to pull because it knows that I love Paper, it knows that I love their shaders." 收到 accept 后, 参会者会拿到一张个性化 ticket, 上面写着自己的名字 + 城市, 背景还是同一个 shader。大家都晒到 social 上, 很多人说这是第一次来 SF。「一年前你能想象做这种东西吗? 不值得做。这些 shader, 一年前做感觉是不可逾越的高山。现在就是 Claude 知道去拉, 因为它知道我爱 Paper, 知道我爱他们的 shader」。
