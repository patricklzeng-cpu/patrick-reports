01任何 DP 内容都能 6DoF 固定

这是眼镜/X1 的原生能力；普通 App 无需理解 Eye，也能让整块屏留在房间里。

02只有特定 App 会“读到”Eye

Beam Pro 主相机 Beta、XREAL SDK FPV，或 Hand Mouse 这类非官方 UVC 项目。

03空间固定不等于空间 API

消费者 OSD 的 Spatial Anchor 固定整块屏；SDK Spatial Anchor 是保存虚拟物体位置，One+Eye 当前不支持。

01官方 · 零安装

Eye 原生拍摄

用镜腿快捷键拍第一视角照片与视频；Eye 提供 12MP 摄像头、EIS，以及最高 1080p 30/60fps 的 One 系列拍摄。

装在眼镜 OSD / 任意兼容主机
Eye直接调用 Eye
为什么值得

这是最纯粹的 Eye 用法：不依赖第三方 App，旅行记录、维修留档、POV 素材随时开拍。

加载步骤与风险＋

边界 / 风险

眼镜本体只有约 2GB 拍摄空间且没有 Photos App；单段 vlog 最长 2 分钟，低光与纯色环境表现有限。

Hand Mouse for XREAL

用 Eye 看手势，MediaPipe 驱动 DeX 鼠标：捏合点击、长捏拖拽、手掌滑动控媒体，还支持语音返回与启动 App。
