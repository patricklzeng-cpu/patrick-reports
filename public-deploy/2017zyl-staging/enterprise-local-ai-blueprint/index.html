02 / REFERENCE ARCHITECTURE

一条调用链，七道控制。

本地化不等于安全。安全来自身份、数据、工具、审批、沙箱、观测与供应链在同一条链上闭环。

DATA PLANErequest → plan → retrieve → act → observe
L1
IDENTITY & GATEWAY统一入口
SSO / OIDCWAF / API Gateway租户与配额数据分级标签
先认证，再路由；用户身份贯穿完整调用链。
L2
ORCHESTRATIONAgent 控制面
LangGraph 状态机任务队列 / Checkpoint人工审批Prompt / Agent 版本
Agent 只生成计划；高风险动作由策略引擎与审批共同放行。
L3

MCP / Tool RegistryOPA 策略代理RAG + ACL沙箱与出口白名单
MCP 只是协议，不是授权；工具发现与每次调用都重新鉴权，检索继承源系统 ACL。

NON-NEGOTIABLE

Agent 不持有生产长期密钥，不绕过网关直连核心系统，不把“模型拒答”当作安全边界。

ADR-01统一 API，不绑定模型

业务只依赖企业模型网关；模型、量化和硬件可独立演进。

ADR-02状态机，不用无限循环 Agent

每个节点有输入、输出、超时、重试、预算和人工接管条件。

ADR-03评测门禁先于上线

每次模型、Prompt、工具或知识变更都跑黄金集与安全回归。

ADR-04观测内容默认前置脱敏

在 SDK 或 OTel Collector 侧先脱敏再发送；Trace 保留因果链，原始 Prompt、附件和工具结果按敏感级别控制。

MODEL PORTFOLIO / 代表性候选

不要选“一个最强模型”，要组一支模型队伍。

版本只作为 2026-08-10 的候选快照，不宣称永远最新。锁定采购前，必须用同一业务黄金集复测质量、延迟、显存和许可证。

主力通用 / 中文多模态Qwen3.5

9B 做边缘与高并发，27B / 35B-A3B 做企业主力；原生图文与工具调用。Apache 2.0。

注意：超长上下文会放大 KV Cache；锁定引擎、Tokenizer、模型 revision 与量化版本。
复杂推理 / 代码DeepSeek

优先评估 R1 Distill 14B/32B；完整 V3.2 属于高速互联多节点项目，不应按“激活参数”估算权重显存。

蒸馏模型同时继承基座许可；工具调用需专项测试异常 JSON、重复调用与越权参数。
国际化 / 生态兼容Llama / Mistral

适合海外语言、既有工具链与边缘场景；不同型号许可证不统一，不能把整个家族视为 Apache/MIT。

每个模型单独登记 LICENSE、AUP、品牌要求、出口限制与商业收入门槛。
专用小模型Embed · Rerank · Guard

Embedding、重排、内容安全、OCR、分类与路由独立部署；不要让通用大模型承担所有任务。

小模型池单独扩缩容，通常能显著降低首 Token 延迟和单次成功任务成本。
LEGAL GATE / 中国大陆“纯内部使用”也需要适用性判断
企业内部

不要机械套用面向公众服务的结论；仍需评估网络安全、数据安全、个人信息、商业秘密、行业监管及劳动用工等义务。

对外服务 / 内容传播

若面向境内公众提供服务或生成内容对外发布，需单独判断备案、安全评估和生成合成内容显式/隐式标识义务。

03 / CAPACITY WORKBENCH

先算峰值，再谈买几张卡。

这是可解释的规划器，不是厂商 benchmark。把默认吞吐替换成你们在目标模型、上下文、量化和并发下的实测值。

PLANNING OUTPUT含 30% 余量 + N+1
建议起配6GPU
日输出量1.8Mtokens / day
峰值需求250output tok/s
负载副本2active replicas
生产副本3含 1 个冗余
4-GPU 节点2向上取整
容量映射02 · Kubernetes 高可用仅按算力规模
计算逻辑峰值 tok/s = 用户 × 请求 × 输出 ÷ 28,800 × 峰谷系数生产副本 = ceil(峰值 ÷ 实测吞吐 ÷ 70%) + 1
采购前必须做什么

用完整 Prompt、目标上下文、真实输出长度与并发曲线压测 TTFT、TPOT、P95/P99、KV Cache、显存与故障恢复；至少跑 30 分钟稳态和 2 次节点故障。

MINIMUM PRODUCTION BOM标准生产最小采购清单

04 / 90-DAY DELIVERY

90 天，不以“模型跑起来”为终点。

每阶段都有可验收的门：价值、平台、业务、生产。任何一门不过，就不扩大算力和权限。
