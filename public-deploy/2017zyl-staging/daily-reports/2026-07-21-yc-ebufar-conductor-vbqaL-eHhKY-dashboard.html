03 · DISPOSABLE

Sodazine 的 bookmark 设计强调「一次性探索」 — 用户 pin 一下 → 探索 → 关闭 → 丢掉, 不做收藏夹沉淀。这是 web 设计的一次范式转移 — 从「永久记录」到「delight 一次性」。Sodazine's bookmark design pushes "single-use exploration" — user pins → explores → closes → discards; no permanent collection accumulation.
