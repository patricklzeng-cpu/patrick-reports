🔥 核心论点🔥 Core thesis

THESIS

Value Maxing ≠ Token Minimization

真正目标是最大化每个成功任务创造的价值。token、延迟和价格都是约束，不是最终 KPI。

The goal is value per successful task. Tokens, latency, and price are constraints—not the final KPI.

CORE

正确优化单位正确优化单位

每个“完成且通过质量门”的任务，而不是每百万 token。

A completed task that passes the quality gate—not price per million tokens.

5 LEVERS

五个杠杆五个杠杆

模型路由、prompt caching、context compaction、程序化工具、batching。

Model routing, prompt caching, context compaction, programmatic tools, and batching.

QUALITY

一个硬约束一个硬约束

任何成本下降都要维持 pass rate，视频以 14% cost reduction + same pass rate 为例。

Every cost reduction must preserve pass rate; the video shows a 14% reduction at the same pass rate.

Combine input, output, reasoning tokens, and retries into task-level cost.

GUARD

Benchmarks are filters; real workloads and pass rates are evidence.

Use frontier models such as GPT-5.6 for complex, long-reasoning, ambiguous work.

ROUTE

Mini / routineMini / routine

Use mini or fast profiles for structured, latency- and cost-sensitive tasks.

Try cheaper models first and escalate on failure or low confidence; avoid one-size-fits-all routing.

🗜 上下文压缩🗜 Context compaction

COMPACT

CompactionCompaction

当会话过长时，通过摘要压缩历史，而不是每轮重传全部上下文。

Compress long histories with summaries rather than resending everything every turn.

STATE

Working memoryWorking memory

保留目标、约束、未完成项、证据和关键决策；删掉冗余过程。

Keep goals, constraints, pending items, evidence, and decisions; drop redundant process.

WARN

Append-only caveatAppend-only caveat

频繁改写历史或插入动态 system 内容会破坏 cache。

Rewriting history or injecting dynamic system content can break the cache.

LATENCY

Fewer round tripsFewer round trips

Return structured results once to reduce round trips and context reinjection.

📦 Tool Batching📦 Tool batching

PARALLEL

Parallel when independentParallel when independent

独立的搜索、读取、计算可以同轮发出。

Issue independent searches, reads, and calculations in the same round.

ORDER

Sequential when dependentSequential when dependent

后一步需要前一步结果、涉及副作用或事务顺序时必须串行。

Serialize steps that depend on prior results, have side effects, or require transaction order.

14% CASE

Measured benefitMeasured benefit

Production example: batching reduced cost by 14% at the same pass rate.
