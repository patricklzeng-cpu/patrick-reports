先说结论。

如果目标是尽快做出可维护的教育产品，不要把“Google 能看到的 3D”与“可以纳入产品资产库的 3D”混为一谈。三类来源的角色完全不同。

PRIMARY / 立即接入01

NASA 3D Resources / GitHub

模型直接以 GLB 为主，常配 PNG 预览；覆盖地球观测、天文台、空间站、深空探测器和通用 CubeSat。对 Web 数据库最友好。

EXPERIENCE / 外链展示02

Google Arts & Culture

Hubble、ISS、Cassini 等可在线旋转或 AR 体验，教育叙事漂亮；但通常不是清晰的批量资产下载 API，适合“去体验”链接。

REFERENCE / 谨慎采集03

GitHub 社区项目

OpenSpace 等项目能补齐 Tiangong、Euclid、JUICE 等对象，也可借鉴轨道与场景组织；但模型授权需要逐文件核验，不能只看仓库代码许可证。

接入决策矩阵

资源“能打开”不等于“能进入产品”。这里按下载性、授权清晰度、Web 友好度和教育价值做一眼决策。

来源模型获取Web 格式授权判断教育价值建议
NASA 3D Resources / GitHub可直接下载GLB + PNG官方指南清晰，仍需检查第三方标注高：任务覆盖广首批导入
NASA Eyes 下载区部分模型可下载Web 优化模型NASA 媒体规则高：可结合实时任务作为精选入口
Google Arts & Culture以在线浏览 / AR 为主平台内 3D不默认等于可再分发很高：叙事成熟外链，不镜像
OpenSpace / GitHub代码与场景资产项目专用资产逐模型核验高：轨道、时间、场景强补充对象
普通 GitHub / 搜索结果不稳定OBJ/FBX/GLB 混合经常缺失不确定进入隔离审查队列

把“图库”变成
教育数据库

建议不要只存一个 model_url。教学场景需要任务、轨道、观测对象、传感器、尺度和版权信息一起成为一条记录。

先做 20 个“英雄模型”

优先 Landsat 8、Terra、Aqua、GOES、ICESat-2、TDRS、Hubble、JWST、ISS、Voyager 等形态差异明显、故事强的对象。

统一 GLB 与缩略图

保留原始来源；产品侧另存优化版本，控制纹理尺寸、面数、坐标轴、单位和默认镜头。

每个模型挂三层解释

“它是什么”适合 8 岁，“它如何工作”适合 12 岁，“数据与轨道”适合高中及以上。

授权与溯源不可后补

每条记录存 source_page、download_url、rights_note、retrieved_at 和文件哈希，避免以后无法追溯。

核验过的入口

这些链接是本页结论的主证据。数据库卡片还会直接进入对应 GitHub 文件夹。

NASA 3D Resources / GitHub

官方仓库说明其目标是提供 NASA 内部的 3D 模型、纹理与图像；目录中可直接看到大量 GLB 与 PNG 文件。

打开官方仓库 ↗

NASA Eyes / 3D Models

NASA 说明 Eyes 团队会把复杂任务 CAD 转成适合 Web 的轻量模型；页面也提供 Europa Clipper、Juno 等模型下载。

打开 NASA Eyes ↗

Google Arts & Culture / Solar System

集合页列出 73 个 3D 对象，其中航天器包括 Hubble、ISS、Cassini、Mars Exploration Rovers 等。

打开 3D 集合 ↗

NASA Images & Media Guidelines

NASA 表示 3D 模型所用纹理和多边形数据通常在美国不受版权保护，可用于教育和信息用途，但必须注意 NASA 标识与第三方材料。
