ACP (Agent Client Protocol) 把本地已装的 Claude Code / Codex / Grok / Cursor / Kimmy 各自做成 agent 加进 channel — 关键价值是 context 跨 agent 跨 harness 自动传递 (Codex 的 skills 跟 memory 转到 Claude Code 不用 re-setup) 跟 turn 控制 (Buzz harness 限制最少 turn 数防 multi-agent 死循环)。 ACP (Agent Client Protocol) wraps your locally installed Claude Code / Codex / Grok / Cursor / Kimmy into agents added to channels — key value is context cross-agent cross-harness auto-pass (Codex skills & memory flow into Claude Code without re-setup) + turn control (Buzz harness limits minimum turns to prevent multi-agent death loops).
