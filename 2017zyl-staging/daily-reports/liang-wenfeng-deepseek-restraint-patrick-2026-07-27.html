01 · EXECUTIVE READ

一页读懂

先抓住梁文锋反复回到的同一个问题：什么能提高做成 AGI 的概率？
DeepSeek 的底层战略可以压缩成一句话：不最大化眼前能拿走的利益，最大化长期做成 AGI 的概率。
愿景 × 克制 × 团队稳定 × 算力效率 → AGI 成功概率 ↑
北极星

AGI 是主线，产品是沿途产物

C 端用户、B 端 API、收入与产品并非不要，而是不让它们反过来支配研究方向。

竞争策略

开源与低价不是慈善，是克制型进攻

主动限制利润诉求，换取人才凝聚、生态支持与更低的外部阻力；真正壁垒落在部署成本和工程效率。

唯一红线

团队稳定性不可退让

资金、卡和时间都能补，核心团队一旦散掉，研究积累和共识难以重建。

技术判断

Agent 之后是持续学习

语言模型 → CoT → Agent → 持续学习 → 自我迭代 → 具身智能，是他给出的“阶梯式”路线。

现实瓶颈

中国与美国的主要差距是资源

人才差距被归因于实验机会与算力差距；国内策略是以更小模型、更低成本和更快工程迭代追赶。

战略下注

不追热点，只做智能主线

视频生成、3D、世界模型与垂直 Agent 被暂时降级；多模态和搜索被视为组件，而非智能本身。

02 · STRATEGY

“克制”不是姿态，是资源配置

开源、低价、不抢 C 端、不做全产业链，其实是同一个决策。

1. 愿景取代 KPI，先回答“为什么存在”

愿景不是墙上的句子，而是公司实际怎么定价、开源、选项目和分配注意力。它承担了组织协议的角色。

愿景 = 选择什么 + 放弃什么 + 如何对待外部世界

2. 克制的四个落点

  • 利润克制：API 以约十个月回收设备成本为标尺，而非价格最大化。
  • 产品克制：不把流量高峰变成“下一个超级 App”战争。
  • 边界克制：不做所有应用、不向上下游无限整合。
  • 竞争克制：愿意帮助同行复现开源模型，因为市场足够大。

3. 开源为什么能赚钱

论点不是“开源没有成本”，而是 DeepSeek 相信第三方很难复制其部署效率。只要服务价格接近成本前沿，第三方即使拿到权重也难以形成更便宜的替代。

权重开放 ≠ 推理成本开放 ≠ 工程能力开放

4. 这套战略的隐含前提

  • DeepSeek 必须长期保持显著的成本工程优势。
  • AGI 路线的长期价值必须大于短期产品机会。
  • 愿景驱动在组织扩张后仍能产生真实共识。
  • 融资与 API 收入足以覆盖高强度算力投入。

持续学习

像员工一样积累环境上下文，而非每次从零开始。

05

06

具身智能

进入物理世界，解决真实的人力需求。

主线

训练、Agent、持续学习、自我迭代

直接决定智能上限，优先获得研究注意力。

组件

多模态、搜索、产品体验

重要且会做，但它们扩展输入输出，不被视为智能主线本身。

暂缓

视频、3D、世界模型、垂直 Agent

可能是好生意，但目前不是 DeepSeek 认定的关键瓶颈。

核心飞轮

下一代模型首先服务 DeepSeek 自己的研发：模型越能辅助研究，下一版模型来得越快；研发加速又反过来提升模型。这是“没有突变临界点、但增长可能非线性”的来源。

04 · COMPUTE

算力差距与成本战争

本页所有具体数字均来自未官方确认的转写稿，风险等级高于战略观点。

文件中的算力叙事

  • 当时约有 2 万张 H 等效算力，并在激进扩充。
  • 若一年能花掉 200 亿元买到合理价格的卡，被视为采购成功。
  • 美国最大模型被描述为约 800B 激活参数，国内仍在几十 B 级别。
  • 训练同级模型，文件估算需约 5 万张 GB300或20 万张华为 950。

阅读数字的正确方式

把它们当作“数量级判断”，不要当作财务或采购披露。转写稿存在 ASR 错词，型号、参数和金额又最容易被误识别；会议本身也不是正式公告。

05 · ORGANIZATION

一半正式，一半自由

不是“无管理”，而是把管理对象从任务清单改成方向、共识和边界。
Top-down · ≤50%

正式项目线

发模型、做效率实验、集体交付时需要清晰分工与协作。随着组织扩大，部分部门会建立更严谨的层级。

Bottom-up · ≥50%

自由探索线

研究员自己判断重要问题，无 KPI、无需为每个想法协调资源。低资源高不确定研究被称为“摸奖”。

为什么不太加班

  • 研究需要松弛环境，持续高压会损害探索。
  • 公司主动聚焦，少做大量非主线补齐工作。
  • 产品不完善被视为有意识的取舍，而非必须立刻修平。

组织的唯一硬约束

团队稳定是唯一不可克制的核心利益。融资、期权、愿景与研究环境，最终都服务于降低核心人才流失风险。

规模化张力

梁文锋承认“没有组织架构”不能无限延伸：未来会同时存在严谨层级部门与松散扁平部门。这是愿景驱动从创业期进入规模期必须补上的操作系统。

06 · BUSINESS

商业化是护城河，也是保底

不是拒绝赚钱，而是决定赚什么钱、什么时候赚、赚到什么程度。
层级梁文锋的定位价值风险
AGI 研究唯一主线决定长期智能上限与公司命运时间、算力与高质量数据不确定
API / B 端沿途产出 + 现金流最坏情况下也可能支撑一家上市公司需求上限有限，数字未审计
C 端产品低成本保留未来可能有用的用户资产若重投入抢流量，会偏离研究主线
通用 / Coding Agent近期应用优先级最高连接研究能力与实际生产力仍受持续学习能力限制
垂直 Agent暂缓金融、医疗等潜在市场大过早做会分散资源

定价护城河

以约十个月回本为标尺，意图把服务压到第三方难以盈利的成本区间。

行业终局

国内基础模型公司会从分散走向约三四家，利润回归合理区间。

梦想与保底

上限是 AGI，下限是把现有 API 和服务经营成可持续公司。

09 · COUNTERVIEW

最该保留的五个问号

好的总结不是替作者加固叙事，而是标出叙事在哪些地方会失效。
01 · 真实性

会议可信 ≠ 每个字、每个数字可信

自动转写、AI 整理、未区分说话人，会在专有名词、芯片型号、参数与金额上放大错误。

02 · 路线下注

持续学习未必是唯一下一台阶

这是 DeepSeek 的研究判断，不是行业共识。世界模型、多模态、具身与工具使用可能并行推进，而非严格串行。

03 · 组织扩张

愿景驱动会遇到协调成本

人数增长后，隐性共识会分裂；“没有 KPI”若缺少评估和责任边界，容易把自由变成不可见的低效。

04 · 开源经济学

成本优势必须持续领先

若云厂商、芯片商或模型压缩工具快速抹平部署差距，开源与商业化“不冲突”的前提会被削弱。

05 · 资本纪律

“把钱都变成卡”不是普适原则

供应、折旧、能耗、模型路线变化和需求波动都可能让算力资产错配；这更像高速增长阶段的特定判断。

最终判断

最值得学的不是某个数字，而是取舍一致性

从愿景、定价、开源、产品边界、组织时间到合作伙伴选择，所有决策都指向同一个目标。即使不同意路线，也值得研究这种战略一致性。

三条带走

① 先决定唯一主线，再允许商业化成为副产物；② 真正的壁垒常在成本和组织，而不只在模型权重；③ “持续学习”若要进入 Patrick/Hermes，必须同时带上评估、回滚与人工晋升门。
