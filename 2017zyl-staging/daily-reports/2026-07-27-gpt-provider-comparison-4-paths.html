2 · #4 OpenAI Platform 实际配置 (1 entry 即 ship)

📝 <copy to ~/.hermes/auth.json providers block>

{
  "providers": {
    "openai": {
      "type": "openai",
      "baseUrl": "https://api.openai.com/v1",
      "apiKey": "${OPENAIPOOL}",
      "authHeader": "Bearer",
      "enabledModels": ["gpt-5", "gpt-5-mini", "gpt-5-nano", "o3", "o3-mini", "gpt-image-2"]
    }
  }
}
Key: authHeader: "Bearer" 跟 minimax 的 sk-cp-... bearer 模式一致 (memory PITFALL pi 0.80.6 minimax provider 配法)。

🔑 Token 获取

  • platform.openai.com → Billing → 充值 ≥ $5 (¥30 起)
  • platform.openai.com → API keys → 创建 sk-... (51 chars 起 "sk-proj-...")
  • 贴进 credential_pool.OPENAIPOOL 防裸词落到文件
  • 沙箱 timeout 不影响本机拿 key

🔁 跟现有 3 provider 并存
