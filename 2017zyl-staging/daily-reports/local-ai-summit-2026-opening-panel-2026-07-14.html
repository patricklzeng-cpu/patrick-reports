🧩 5 Themes

Theme 1 · The 2026 Inflection Point — Models AND Harnesses

The panel rejects "model-only" framing. Karpathy's November 2025 tweet ("can't trust coding agents alone — monitor with eye like a hawk") → 3 months later ("struggling to keep up") both correct, encapsulating the speed of change. The inflection has three drivers:

  1. Reasoning models changed the response profile: plateau phase (tokens user doesn't consume) + burst output
  2. Agents demand always-on infrastructure (not chat-boxes)
  3. Harnesses (Cursor-style file system access, CLI tools, multimodal peripherals) unlock real productivity

Enterprise + consumer pain points (privacy + cost): both want to bring IP/health data into AI without leakage; both want cost-plateaued token generation. Local AI solves both.

Theme 2 · Multimodel Routing Is the New Default

"Your most intelligent should provide you with the overall plan and then subtasks for your smaller executioner like executioner models. And that's exactly the future."

Coinbase example (Brian Armstrong post): tokens exploding, costs flat → because they're using mixture of different models. The obvious application: top model plans architecture, smaller models execute code.

Market-driven, not vendor-driven: "They don't want to be told what they can do by Dario. They don't want to be paying for the same model for all their workloads when some workloads don't actually need a gigantic model that costs $50 per million tokens."

Three open problems with multimodel:

  • Routing logic itself
  • Context propagation to sub-agents
  • Version control (which version changed behavior later?)

Theme 3 · Specialized Small Models Beat One-Model-Rule-Them-All

"There was like one model will rule them all world was kind of thought and I feel like the pendulum is swung back to people realizing specialized."

Vision world learned this first (limited compute at edge → specialized learners). Now LLM world following same path. Two patterns:

  1. Direct fine-tune (e.g., fine-tune SAM 3) — but loses open-vocabulary capability
  2. Distillation (use large general model + LMS-as-judge consensus → specialized data set → small efficient model)

Roboflow example: Monterey Bay Aquarium Research Institute uses SAM 3 + LLM judges to build autolabel pipelines for deep-sea footage, then distills to specialized small model that runs on submarine in real-time.

Coinbase + Brian pattern: frontier models bootstrap efficient open-source setups.

Theme 4 · Local + Open Source Wins = Right to Intelligence

Ahmed's call to action: "This has been my stance for years now. I have been saying open source AI must win... The way we do that is by giving the people... an easy way to use these models in a very efficient way that doesn't give them headaches more than solve their problems."

right to intelligence.org (announced by panel): "A way for you to get involved and actually advocate for open source and ensure that we maintain freedom of intelligence."

Silicon Valley tension argument: computation invented on East Coast, Silicon Valley happened because hippies shared ideas for free in software. Capitalists + hippies coexist — that's the productive environment.

Theme 5 · DGX Spark 10x Engineering Story

Three-week optimization sprint (Alex Chen at NVIDIA HQ with Nata coordinating):

  • Started with Nata's Thursday dinner idea → Friday email → Monday in conference room
  • Jensen's "swarming" concept mobilized teams: Neatron / data center / VLM / quantization
  • Goal: squeeze every drop of performance on DGX Spark
  • Result: 10x performance vs NVIDIA's existing playbook

Key insight: "We didn't solve any new computer science. We actually took things that the experts at NVIDIA had already solved and was out there... we assembled it in a bouquet."

Hardware = same as data center (Grace Blackwell): kernels already good, but tuning/config designed for data center. Spark = data center hardware on desk.

Numbers:

  • Neatron 3 Ultra 550B param model on 4 Sparks at 30 tokens/second
  • Qwen 3.5 4B ≈ GPT-4 quality on iPhone
  • Llama 45B (2023 era) closing frontier gap at 2 tok/s → 2026: small models at usable speed
