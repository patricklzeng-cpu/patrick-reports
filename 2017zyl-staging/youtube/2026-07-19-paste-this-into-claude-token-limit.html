THE MODEL
先看公式：Token 上限其实是 Compute Budget 问题Start with the equation: token limits are really a compute-budget problem

作者先拆开三个常被混淆的概念：tokens 是模型要处理的文本量；model 决定每个 token 需要多少计算；compute budget 是账户可用的总计算额度。撞上限制，不一定意味着你“写了太多字”，而可能是 token × 模型成本把预算用完了。The creator separates three ideas people often conflate: tokens are the amount of text processed; the model determines compute per token; and the compute budget is the account-level allowance. Hitting a limit does not necessarily mean “too many words”; it can mean token volume multiplied by model cost exhausted the budget.

compute budget used=tokens consumed×model used两条杠杆：少喂一点，或让更便宜的模型做简单工作。
Two levers: send less context, or route simple work to a cheaper model.

SYSTEM UPGRADES
Part 2：系统升级的三个层次Part 2: three system upgrades

系统升级把“手动习惯”变成“默认管线”：先压缩输入，再按任务选模型，最后把可重复步骤交给脚本。System upgrades turn manual habits into defaults: compress input, select models by task, then move repeatable steps into scripts.

01INPUT

压缩输入后再交给 AICompress before the AI sees it

不需要让 Claude 读完整 10 页报告，只因为你改了第 1 页。用 hooks、skills 或 RTK 先过滤重复、格式噪声和无关内容。Claude does not need the full 10-page report just because page one changed. Use hooks, skills, or RTK to remove repetition, formatting noise, and irrelevant content first.
02ROUTING

给重复工作降模型Use smaller models for grunt work

抓取、格式化、摘要等一年前就能做的任务，不一定值得使用 frontier model。Scraping, formatting, and summarizing may not need a frontier model if AI could solve the task a year ago.
03AUTOMATE

把重复步骤脚本化Script repeatable steps

脚本每次按同样规则执行，零 token、可复现、不靠模型临场重新发明流程。A script runs the same way every time, uses zero model tokens, and does not reinvent the workflow on every run.
分工原则：AI 做判断；脚本做可重复的机械步骤。脚本不是“更聪明的 agent”，而是把不需要判断的部分从 agent loop 里拿掉。Division of labor: AI handles judgment; scripts handle repeatable mechanics. A script is not a “smarter agent”—it removes work that never needed judgment from the agent loop.

模型决定能力/成本；context fork 决定是否带入前序信息。两者都能单独调节。Model controls capability and cost; context fork controls inherited information. Tune them independently.
